## ParaFlow · 从这里开始 / Start Here

启用 ParaFlow 后，主题可以先选 Follow Obsidian（跟随 Obsidian）或 ParaFlow Classic。

首先用 [Markdown 语法展示](Markdown%20syntax%20showcase.zh.md) 体验 ParaFlow 的整体样式（列表、段落、表格、公式与主题等），然后再选择一些更详细的样例（可以尝试一下各种按键，比如 Enter、Tab、Backspace、Shift + Enter/Tab 等）：

+ [列表、引用与 Callout](features/Lists%20quotes%20and%20callouts.zh.md)：拆分与续行、调整层级、任务框，以及容器中的编辑。
+ [公式与代码块](features/Math%20and%20code%20blocks.zh.md)：行内公式预览、块公式编辑、代码换行、行号与复制。
+ [Markdown 与 HTML 表格](features/Markdown%20and%20HTML%20tables.zh.md)：单元格编辑、行列调整、对齐、跨行与跨列。

---

Enable ParaFlow and start with Follow Obsidian or ParaFlow Classic.

Explore the overall appearance of lists, paragraphs, tables, math, and themes in the [Markdown syntax showcase](Markdown%20syntax%20showcase.en.md), then choose a detailed example below. Try keys such as Enter, Tab, Backspace, Shift+Enter, and Shift+Tab as you edit.

- [Lists, quotes, and Callouts](features/Lists%20quotes%20and%20callouts.en.md): Split items, add continuation lines, change levels, toggle tasks, and edit inside containers.
- [Math and code blocks](features/Math%20and%20code%20blocks.en.md): Preview inline math, edit display math, and explore code wrapping, line numbers, and copying.
- [Markdown and HTML tables](features/Markdown%20and%20HTML%20tables.en.md): Edit cells, adjust rows and columns, change alignment, and explore spanning cells.



## Misc

这个库中还进行了一些设置：
1. 快捷键：
   + 标题：`set as heading <Num>` -> `Ctrl + <Num>`
   + 切换源码模式：`Toggle Live Preview/Source mode` -> `Ctrl + /`
   + 使用默认软件打开：`Open in default app` -> `Ctrl + Shift + O`
1. 关闭 `设置 > 编辑器 > 显示/限制行宽`
2. 保留 6 个 CSS snippets，默认全部关闭，可在外观设置中按需启用。

---

This vault also includes the following settings:

1. Keyboard shortcuts:
   - Headings: `Set as heading <Num>` → `Ctrl + <Num>`
   - Switch between Live Preview and Source mode: `Toggle Live Preview/Source mode` → `Ctrl + /`
   - Open in the default application: `Open in default app` → `Ctrl + Shift + O`
2. **Settings → Editor → Display → Readable line length** is turned off.
3. Six CSS snippets are included and disabled by default. Enable them individually in Appearance settings as needed.
