Alternatively, extract the complete ZIP into `<vault>/.obsidian/plugins/paraflow/themes/<directory>/`, with `theme.json` directly inside that directory. Keep all package subdirectories and `assets/`, then click the refresh icon beside ParaFlow's theme list. Copying a complete theme folder from this repository also works. Each theme ID must be unique; back up personal edits before replacing a manually installed theme.

GitHub's Code → Download ZIP downloads the entire repository; the links above download individual themes or packages.

GitHub, Pixyll, Whitey, and Newsprint follow Obsidian's light/dark mode. Night stays dark. Newsprint's dark palette uses warm gray paper colors while retaining its serif typography and layout.

Plugin upgrades update unmodified bundled files and retain personal styles. Put custom styles in `overrides.css`; directly edited `theme.css` files remain unchanged. Update other packages by importing their ZIP; an existing ID creates a separate copy.
