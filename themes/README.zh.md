[English](README.md) | 中文

也可以将 ZIP 完整解压到 `<vault>/.obsidian/plugins/paraflow/themes/<目录名>/`，使该目录直接包含 `theme.json`。保留包内子目录和 `assets/`，随后点击 ParaFlow 主题列表旁的刷新按钮。复制本目录中的完整主题文件夹也适用；同一主题 ID 只能安装一次，更新已有手动安装前请备份个人修改。

GitHub 的“Code → Download ZIP”下载整个仓库；上表提供单主题／主题包下载。

GitHub、Pixyll、Whitey 和 Newsprint 随 Obsidian 深浅模式切换，Night 保持深色。Newsprint 深色版采用暖灰纸张配色，保留原有衬线字体和排版。

随附主题在插件升级时更新未修改的官方文件，并保留个人样式。自定义样式请放在 `overrides.css`；直接改写的 `theme.css` 保持原样。其它主题包通过导入 ZIP 更新，已有 ID 会生成独立副本。
