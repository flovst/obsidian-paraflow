# ParaFlow bundled theme input

This is ParaFlow's adapted input based on Typora 1.9.5 bundled `whitey.css` from [typora-default-themes](https://github.com/typora/typora-default-themes). It is included in exported ParaFlow theme packages for editing and reconversion. Upstream copyright and resource notices remain applicable.

The adaptation removes the earlier metadata `font-size: 0.9em` declaration overridden by `font-size: 0.76em` in the same rule. Conversion removes the corresponding earlier custom property; the effective metadata size remains `0.76em`.
