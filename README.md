# ParaFlow

ParaFlow is an Obsidian plugin for structured Markdown editing.

## Build

Requires Node.js 20 or later and npm.

```sh
npm ci
npm run build
```

Copy `main.js`, `manifest.json`, and `styles.css` into your vault's `.obsidian/plugins/paraflow/` directory.
