# ParaFlow themes

Read the module for the requested task:

- [Inspect](workflows/inspect/SKILL.md): source, dependencies or a visible difference.
- [Convert](workflows/convert/SKILL.md): import, repair or export a content theme.
- [Appearance](workflows/appearance/SKILL.md): explicitly requested light/dark pairing or counterpart generation.

For source-specific work, read only the relevant module: [Typora](sources/typora/SKILL.md), [MarkText](sources/marktext/SKILL.md), [VNote](sources/vnote/SKILL.md), [Zettlr](sources/zettlr/SKILL.md), [Joplin](sources/joplin/SKILL.md), or [generic CSS](sources/generic-css/SKILL.md). Follow these links directly; load a script's implementation when changing it or investigating its result.

Use supplied files and the authorized target vault. Preserve original inputs, attribution and user overrides. Keep downloads within the request; check theme and asset licenses before redistribution. Report the result and specific remaining differences.
