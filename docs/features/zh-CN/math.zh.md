# 公式

[文档索引](../../README.zh.md) · [English](../EN/math.en.md)

ParaFlow 提供行内公式预览与类似 Typora 中的公式块编辑。

## 使用

<video src="../assets/videos/math/edit-math.mp4" controls=""></video>

主要是修改配色方案（原版超绝红配绿，这谁绷得住），提供预览与优化编辑：

+ Inline math：增加行内公式的预览
+ Block math：隐藏边界 `$$` 符号，避免误编辑；如果确实需要，也可以进入 Source Mode 修改

## 设置

在 **设置 → ParaFlow → 编辑 → 公式** 中开关公式增强，可以选择不同的语法高亮配色方案：One Light、Solarized、Light+、跟随 Obsidian 或 Typora。

调整内容主题时，可以同时观察行内公式与正文的基线、间距，以及公式块前后的段间距。
