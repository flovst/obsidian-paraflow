# 内容主题

[文档索引](../../README.zh.md) · [English](../EN/themes.en.md)

ParaFlow 目前自带了 Typora 中的 5 个默认主题，可以在设置界面调整。

目前设置页面中提供了一个测试用的 Typora 主题导入，但还不稳定。源码中提供了一个用来导入 Typora 主题的 Skill，如果你有想要的主题，我更推荐把这个交给你的 agent 试试。

ParaFlow 设置使用 **主题**、**编辑**、**其它** 三个原生子页面。可以通过 Obsidian 设置搜索按名称和说明查找具体选项，已禁用模块内的选项也能被搜索到。



## 导入 Typora 主题（测试中）

1. 点击“导入主题”，选择 CSS 文件、ZIP 包或主题文件夹。
3. 点击“预览转换”，查看已映射、近似转换和跳过的规则。
4. 点击“保存主题”，再从主题菜单中选择并应用。

导入目录默认按主题名称生成，例如 `typora-github`。导入主要处理本地 CSS 和资源，不会下载远程资源。

转换报告用于定位具体规则和资源问题。没有可转换的正文规则、缺少必需的 CSS 导入文件或存在无效路径等情况会阻止保存；缺少可选字体或图片会在报告中说明。

#### 调整主题文件

通过“打开主题文件夹”找到当前主题。通常位于笔记库插件目录下的 `paraflow/themes/<theme-id>/`：

| 文件或目录 | 内容 |
| --- | --- |
| `theme.json` | 主题信息 |
| `theme.css` | 转换生成的样式 |
| `overrides.css` | 用户补充的样式 |
| `conversion-report.json` | 转换报告 |
| `assets/` | 本地字体与图片 |
| `source/` | 导入的源文件 |

编辑 `overrides.css` 后点击“重新加载”。可使用内容元素选择器、Obsidian 内容类名和 `:root` 变量。例如：

```css
h1 { color: #225588; }
.cm-header-1 { color: #225588; }
```

本地资源使用 `url(assets/文件名)`。补充样式支持普通规则、`@media` 和 `@supports`；字体注册通过源主题导入处理。

分别检查阅读视图和实时预览中的结果。主题管理会对补充样式限定作用范围。

#### 导出

“导出”将导入主题的源文件、资源、补充样式和报告打包为 ZIP。重新导入时会再次转换。主题菜单中的字体、宽度等本地调整单独保存在插件设置中，不包含在主题导出包内。
