# 内容主题

一个主题目录可以保存单个主题，也可以保存包含多个主题的主题包。包内主题共享资源，仍可分别选择。导入主题包 ZIP 或文件夹会安装其中的主题；导出选中的主题会生成可独立使用的 ZIP。

[文档索引](../../README.zh.md) · [English](../EN/themes.en.md)

ParaFlow 内置 55 套主题，来自 ParaFlow Classic、Typora、Joplin、MarkText、VNote 和 Zettlr，可在设置或主题管理中选择。

设置页面提供了测试用的Typora主题导入。源码中的 [paraflow-theme Skill](../../../skills/public/paraflow-theme/SKILL.md)可辅助agent检查和适配Typora、MarkText、VNote、Zettlr、Joplin及其它CSS来源的主题。

主题选择框左侧的刷新图标会重新扫描已安装主题，并重读当前主题文件。“管理主题”在桌面打开独立窗口，移动端打开工作区标签页。列表支持搜索，以及配色方案、主题包、来源和安装类型过滤；缺少来源信息显示“-”。

主题包与独立主题名称对齐，使用常规字重；子主题缩进显示，展开包有细边框。单击包行展开或折叠。搜索和过滤时显示命中主题及其父包，清空条件后恢复原展开状态；排序保留包与成员的层级。五个随附 Typora 主题组成一个包，ParaFlow Classic 独立显示。

单击主题行选择，双击使用主题，右键打开使用主题、打开文件夹、导出、报告和主题信息等操作。在主题信息中可编辑来源与“主题包 ID”：相同 ID 的主题归入同一包，留空后成为独立主题。包行右键提供展开／折叠和主题包信息。来源与分组信息随导入导出保留。

点击表头单元格任意位置切换升降序；拖动时显示标题浮影，按光标所在半列标出前／后插入线，松开后插入该处，按 Esc 取消。表头聚焦后可用 Alt+左右键移动。列顺序、排序与包展开状态随工作区保存。表头左对齐并有分隔线，排序箭头保留固定宽度；管理控件保留可访问名称，默认不显示悬浮提示。

支持深浅两套配色的主题（如 Typora GitHub）随 Obsidian 当前实际使用的深浅模式切换，包括跟随系统的变化。单配色主题保留自身颜色。应用配色方案在 Obsidian 的外观设置中调整；主题管理按主题声明标记“深/浅色”“深色”“浅色”。



## 导入 Typora 主题（测试中）

1. 点击“导入主题”，选择 CSS 文件、ZIP 包或主题文件夹。
2. 点击“预览转换”，查看已映射、近似转换和跳过的规则。
3. 点击“保存主题”，再从主题菜单中选择并应用。

导入目录默认按主题名称生成，例如 `typora-github`。导入主要处理本地 CSS 和资源，不会下载远程资源。

插件升级时保留已有Typora主题目录。要安装更新主题，导入对应ZIP并选择新保存的主题；已有ID会追加数字后缀，旧主题继续保留。个人样式可从旧`overrides.css`选择性迁移。刷新图标用于重读已安装文件。

转换报告用于定位具体规则和资源问题。没有可转换的正文规则、缺少必需的 CSS 导入文件或存在无效路径等情况会阻止保存；缺少可选字体或图片会在报告中说明。

#### 调整主题文件

通过“打开主题文件夹”找到当前主题。通常位于笔记库插件目录下的 `paraflow/themes/<theme-id>/` 或 `paraflow/themes/<package-id>/<theme-id>/`：

| 文件或目录 | 内容 |
| --- | --- |
| `theme.json` | 主题信息 |
| `theme.css` | 转换生成的样式 |
| `overrides.css` | 用户补充的样式 |
| `conversion-report.json` | 转换报告 |
| `assets/` | 本地字体与图片 |
| `source/` | 导入的源文件 |

编辑 `overrides.css` 后点击主题选择框左侧的刷新图标。可使用内容元素选择器、Obsidian 内容类名和 `:root` 变量。例如：

```css
h1 { color: #225588; }
.cm-header-1 { color: #225588; }
```

独立主题资源使用 `url(assets/文件名)`，包内共享资源使用 `url(../assets/文件名)`。补充样式支持普通规则、`@media` 和 `@supports`；字体注册通过源主题导入处理。

补充样式仅作用于内容区域。修改后可分别查看阅读视图和实时预览。

#### 导出

“导出”将导入主题的源文件、资源、补充样式和报告打包为 ZIP；重新导入普通主题时会再次转换。已声明深浅配对的主题包保留转换后的两套样式。
