# 行内格式、链接、图片与脚注

[文档索引](../README.zh.md) · [English](inline-and-media.en.md)

ParaFlow 在实时预览中提供行内格式的源码显隐，以及链接、图片和脚注的编辑与导航。

## 使用

- **行内格式**：进入粗体、斜体、行内代码等内容的编辑位置时查看源码，离开后恢复渲染。上下标示例为 `H~2~O` 和 `x^2^`。
- **链接**：默认单击进入链接源码编辑，按住 `Ctrl` 单击打开链接。可以在设置中将单击操作改为打开链接。
- **图片**：启用“进入编辑位置时显示源码”后，单击图片或将光标移到图片边缘会显示可编辑的图片链接。独立图片可以居中显示；显式尺寸与对齐设置会参与显示。
- **脚注**：通过引用跳转到定义，并返回正文。编辑时保留脚注名称和定义内容，可检查完整 Markdown 标记。

## 设置

在 **设置 → ParaFlow → 编辑** 中分别调整：

| 分组 | 主要设置 |
| --- | --- |
| 行内格式 & 链接 | 单击链接时的操作、上下标、Obsidian 注释显示 |
| 图片 | 进入编辑位置时显示源码、图片居中 |
| 脚注 | 脚注显示与导航增强 |

Obsidian 注释可以始终显示，或仅在编辑时显示。需要核对链接目标、图片路径和脚注标记时，可切换到源码视图。
