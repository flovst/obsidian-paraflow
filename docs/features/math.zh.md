# 公式

[文档索引](../README.zh.md) · [English](math.en.md)

ParaFlow 提供行内公式和公式块的预览、源码编辑与块内导航。

## 使用

用 `$...$` 编写行内公式，用 `$$` 包围公式块。在实时预览中点击公式进入源码编辑，移开焦点后查看渲染结果。

公式块可以包含多行表达式、对齐环境和矩阵。渲染使用 Obsidian 的数学公式引擎；源码配色设置调整编辑时的语法颜色。

## 设置

在 **设置 → ParaFlow → 编辑 → 公式** 中开关公式增强，并选择语法高亮：One Light、Solarized、Light+、跟随 Obsidian 或 Typora。

调整内容主题时，可以同时观察行内公式与正文的基线、间距，以及公式块前后的段间距。公式源码中的命令决定公式内容与结构。
