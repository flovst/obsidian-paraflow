# 视图与复制粘贴

[文档索引](../README.zh.md) · [English](views-and-clipboard.en.md)

ParaFlow 在实时预览中提供编辑增强，在阅读视图中显示内容样式，并为源码视图提供行号、空白字符等编辑辅助。

## 切换与检查

在实时预览中编辑内容，切换到阅读视图查看渲染，或切换到源码视图检查 Markdown。内容主题会应用到实时预览和阅读视图；源码视图共享字体、颜色、宽度和标题文字样式，同时保留源码标记。

在 **设置 → ParaFlow → 编辑 → 源码视图** 中，可以调整当前行高亮、空白字符、缩进参考线、换行符和行号。

行号可以显示全部行，或仅显示每 10 行与光标所在行，并可放在编辑器左侧或正文左侧。源码 Tab 宽度为 1–8 个字符列，只影响源码显示。

换行符显示中，普通源码换行为 `↵`，以两个空格结尾的 Markdown 硬换行为 `↴`。视觉折行和没有换行符的文件末尾不加标记。

## 复制与粘贴

选择 Markdown 内容复制时，ParaFlow 保留对应的源码表示。可在源码视图粘贴检查标记、缩进与空行。

在 **编辑 → 复制 & 粘贴** 中为源码视图与实时预览分别选择粘贴方式：

| 方式 | 行为 |
| --- | --- |
| 精确文本 | 保留剪贴板可提供的原始文本表示 |
| 智能粘贴 | 使用 Obsidian 的富文本转换与附件处理 |

默认源码视图使用精确文本，实时预览使用智能粘贴。命令面板中的 **本次精确粘贴 / Paste exact text** 和 **本次智能粘贴 / Smart paste** 可以覆盖单次操作，不必修改默认设置。该分组还提供“粘贴时补全代码块边界”。

其它插件也可能处理复制粘贴；遇到结果差异时，可以对同一段文本分别尝试两种粘贴命令。

## 相关设置与示例

**鼠标 & 选区** 提供禁止拖动选区文字、选区时隐藏光标。切换模式时的源码整理见[列表与任务](lists.zh.md)。

使用 [Markdown 语法展示](../../dist/showcase/Markdown%20syntax%20showcase.zh.md) 对比三个视图，并尝试复制带格式的文本、列表和代码。
