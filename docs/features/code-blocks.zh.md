# 代码块与 Mermaid

[文档索引](../README.zh.md) · [English](code-blocks.en.md)

ParaFlow 为代码块提供行号、长行换行、语言控件与源码配色，并管理代码围栏边界、块内导航和选择。

## 使用

使用三个反引号创建围栏代码块，并在起始围栏后填写语言名称，例如 `ts`。在实时预览中编辑代码，可以通过语言控件调整语言。

显示行号用于定位代码。复制代码块内容时，显示行号不会进入复制结果，代码中的缩进和空行会保留。长行显示方式可以在自动换行与横向查看之间切换。

Mermaid 图表提供独立的源码编辑与预览开关。使用 `mermaid` 围栏编写图表，然后查看预览。

## 设置

在 **设置 → ParaFlow → 编辑 → 代码块** 中调整自动换行、显示行号、语言输入控件的位置和语法高亮。

语言控件可以放在右上角、右下角或关闭。语法配色可以跟随 Obsidian，也可以选择 One Light、Solarized 或 Light+；后三种配色适合浅色背景。配色选择保留语言识别、代码内容与代码块背景。

**编辑 → Mermaid 图表** 控制图表增强；**复制 & 粘贴 → 粘贴时补全代码块边界** 控制相关粘贴辅助。粘贴方式见[视图与复制粘贴](views-and-clipboard.zh.md)。
