# Markdown 与 HTML 表格

[文档索引](../README.zh.md) · [English](tables.en.md)

ParaFlow 提供 Markdown 和 HTML 表格的单元格编辑、行列操作、对齐与合并功能。显示增强包括自动布局、条纹和溢出处理。

## 使用

在实时预览中激活表格单元格，通过表格控件编辑内容、添加或删除行列、调整对齐方式。启用自动换行后，长内容随列宽折行；关闭后，宽表格可以横向滚动。

HTML 表格支持 `rowspan` 和 `colspan`。合并单元格时只保留左上角单元格的内容，操作前应检查选区中的文字。

对 Markdown 表格应用垂直对齐等需要 HTML 表达的格式时，ParaFlow 会将支持的表格转换为标准 HTML。可切换到源码视图检查结果，并通过一次 Undo 还原该次转换。

HTML 单元格内使用 `<strong>`、`<em>`、`<code>`、`<br>` 等 HTML 标签表示格式与换行；任意 Markdown 内容在 HTML 单元格中的嵌套渲染不在支持范围内。

## 设置

在 **设置 → ParaFlow → 编辑 → 表格** 中调整：

| 设置 | 用途 |
| --- | --- |
| 显示增强 | 自动布局、条纹与溢出处理 |
| 编辑增强 | 单元格操作、合并、格式与 HTML 转换 |
| 表格内自动换行 | 在折行显示与宽表格横向滚动之间切换 |
| 单元格合并提示 | 恢复合并时丢弃其它单元格内容的提示 |

显示增强和编辑增强可以分别启用。表格颜色、边框和字体由[内容主题](themes.zh.md)提供。
