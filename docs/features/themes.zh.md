# 内容主题

[文档索引](../README.zh.md) · [English](themes.en.md)

ParaFlow 的内容主题调整笔记正文的字体、颜色和排版，并提供 Typora 主题导入。入口是 **设置 → ParaFlow → 主题**。

## 选择与调整

- **跟随 Obsidian**：使用 Obsidian 的字体与配色，并保留 ParaFlow 的基础标记和布局。
- **ParaFlow Classic**：使用插件提供的正文样式。
- **Typora GitHub**：使用随包提供的 GitHub 正文主题，主题源文件和字体会一并安装。
- **导入的主题**：使用转换后的 Typora 内容样式，一次选择一个主题。

正文字体、字号、宽度、行高和强调色可以使用主题默认值、跟随 Obsidian 或自定义值。每个主题分别保存调整；切换主题后，之前的调整会保留。“重置主题调整”清除当前主题的本地调整。

正文宽度跟随 Obsidian 时会参考其行宽设置。自定义宽度以像素为单位，行高使用倍数。正文字号主要用于段落和列表；标题、代码等具有独立字号的内容保留对应样式。

Metadata 可以与正文对齐或使用 Obsidian 原生布局，并调整水平内边距和下方间距。属性是否显示由 **Obsidian 设置 → 编辑器 → 文档中的属性** 控制。

主题应用于实时预览和阅读视图；源码视图共享部分文字与布局样式，详见[视图说明](views-and-clipboard.zh.md)。

随包还提供 Typora Newsprint、Night、Pixyll 和 Whitey，可在同一主题菜单中选择。

## 导入 Typora 主题

1. 点击“导入主题”，选择 CSS 文件、ZIP 包或主题文件夹。包含字体、图片和 `@import` 文件的主题应保留完整资源。
2. 有多个入口时，选择要转换的 CSS 入口，并填写主题名称。
3. 点击“预览转换”，查看已映射、近似转换和跳过的规则。
4. 点击“保存主题”，再从主题菜单中选择它以应用。

导入处理本地 CSS 和资源；远程资源不会被下载。转换主要覆盖字体、颜色、标题、链接、代码、引用、表格和正文宽度。Typora 特有界面与 DOM 结构相关的规则可能被跳过。

转换报告用于定位具体规则和资源问题，计数不代表兼容百分比。没有可转换的正文规则、缺少必需的 CSS 导入文件或存在无效路径等情况会阻止保存；缺少可选字体或图片会在报告中说明。

导入的主题沿用转换后的配色，配色方案控件不会为它生成单独的浅色、深色版本。源 CSS 中受支持的条件样式会保留。

## 调整主题文件

通过“打开主题文件夹”找到当前主题。通常位于笔记库插件目录下的 `paraflow/themes/<theme-id>/`：

| 文件或目录 | 内容 |
| --- | --- |
| `theme.json` | 主题信息 |
| `theme.css` | 转换生成的样式 |
| `overrides.css` | 用户补充的样式 |
| `conversion-report.json` | 转换报告 |
| `assets/` | 本地字体与图片 |
| `source/` | 导入的源文件 |

编辑 `overrides.css` 后点击“重新加载”。可使用内容元素选择器、Obsidian 内容类名和 `:root` 变量。例如：

```css
h1 { color: #225588; }
.cm-header-1 { color: #225588; }
```

本地资源使用 `url(assets/文件名)`。补充样式支持普通规则、`@media` 和 `@supports`；字体注册通过源主题导入处理。

分别检查阅读视图和实时预览中的结果。主题管理会对补充样式限定作用范围。

## 导出

“导出”将导入主题的源文件、资源、补充样式和报告打包为 ZIP。重新导入时会再次转换。主题菜单中的字体、宽度等本地调整单独保存在插件设置中，不包含在主题导出包内。
