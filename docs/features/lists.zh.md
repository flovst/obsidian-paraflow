# 列表与任务

[文档索引](../README.zh.md) · [English](lists.en.md)

ParaFlow 为无序列表、有序列表和 Markdown 任务列表提供条目创建、拆分、缩进与层级调整。

## 使用

在实时预览中编辑列表：

| 操作 | 用途 |
| --- | --- |
| Enter | 拆分当前条目或创建下一条目 |
| Shift+Enter | 在条目内添加续行 |
| Tab / Shift+Tab | 在适用的列表位置增加或减少缩进 |
| 单击任务复选框 | 切换任务状态 |
| Undo | 撤销编辑或任务状态变化 |

嵌套列表可以保留条目与子条目的层级关系。引用和 Callout 中的列表沿用这些操作，并保留容器前缀。可在源码视图中检查缩进、任务标记与续行。

## 设置

在 **设置 → ParaFlow → 编辑 → 列表 & 任务** 中开关列表编辑。无序列表符号可以按嵌套层级显示，也可以使用固定形状；这一设置调整显示样式。

**编辑 → 其它 → 源码自动整理** 提供四种选项：从不、手动保存时、切换视图时、手动保存或切换视图时。

- 手动保存：在主编辑器中按 `Ctrl+S`，补足列表续行的结构缩进，并根据编辑期间建立的归属补充缺失的零宽分隔符。自动保存和菜单保存不触发这次全文检查。
- 切换视图：同一文件在实时预览、源码和阅读模式之间切换，且编辑器可用时，补足结构缩进。此操作只整理缩进。
- 整理产生的修改可以撤销；没有修改时不会增加撤销记录。

## 源码中的分隔符

结构化编辑可能在 Markdown 中插入 **U+200B 零宽空格**，用来保持段落与列表之间的边界。它是文件中的实际字符。实时预览会隐藏并保护受管理的前缀，源码视图可以检查这些字符。

源码自动整理设置控制额外的整理时机；正常编辑仍会即时插入所需的分隔符。清理源码时应检查具体位置，避免批量删除文件内所有 U+200B 字符。
