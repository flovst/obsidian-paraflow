# 段落、换行与标题

[文档索引](../README.zh.md) · [English](paragraphs.en.md)

ParaFlow 在实时预览中将段落间的单个空行显示为段间距，并保留可编辑的空段落。段落排版还可以调整首行缩进、段间距和制表符的显示。

## 使用

在两个正文段落之间保留一个空行，观察实时预览中的段间距。添加更多空行时，可以将光标放入其中继续输入。

同一段中的 Markdown 硬换行和 `<br>` 可以显示淡色提示，便于区分换行与新段落。切换到源码视图，可以检查原始换行、尾部空格和标签。

标题功能管理 `#` 标记的显示与编辑边界，支持标题的创建、拆分和取消标题格式时的编辑行为。标题的字体与颜色由当前内容主题控制。

## 设置

在 **设置 → ParaFlow → 编辑** 中调整：

| 设置 | 用途 |
| --- | --- |
| 段落 & 换行 | 启用段落间距与换行编辑 |
| HTML 换行标记 | 显示 `<br>` 等标签的换行提示 |
| 首行缩进 | 调整正文段落首行的显示 |
| 段间距 | 调整段落之间的距离 |
| Tab 显示方式、Tab 宽度 | 选择固定宽度或按制表位对齐，并调整宽度 |
| 标题 | 启用标题标记与编辑行为 |

首行缩进、段间距和 Tab 显示调整只影响排版，保留源码中的字符。正文 Tab 宽度使用当前内容字体的空格宽度；源码视图有独立的 Tab 设置。
