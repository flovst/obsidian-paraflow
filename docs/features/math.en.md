# Math

[Documentation](../README.md) · [中文](math.zh.md)

ParaFlow provides previews, source editing, and navigation within blocks for inline and block formulas.

## Use

Write inline math with `$...$` and surround block math with `$$`. In Live Preview, click a formula to edit its source and move focus away to see the rendered result.

Math blocks can contain multiline expressions, alignment environments, and matrices. Rendering uses Obsidian's math engine; the source palette controls syntax colors while editing.

## Settings

Under **Settings → ParaFlow → Editing → Math**, toggle math enhancements and choose a syntax palette: One Light, Solarized, Light+, Follow Obsidian, or Typora.

When adjusting the content theme, observe the baseline and spacing of inline math alongside body text, as well as spacing around math blocks. Commands in the formula source determine its content and structure.
