# Paragraphs, line breaks, and headings

[Documentation](../README.md) · [中文](paragraphs.zh.md)

In Live Preview, ParaFlow displays a single blank line between paragraphs as paragraph spacing and keeps empty paragraphs editable. Paragraph layout also offers first-line indentation, paragraph spacing, and tab display controls.

## Use

Leave one blank line between two body paragraphs and observe the spacing in Live Preview. Additional blank lines remain available for placing the caret and typing.

Markdown hard breaks and `<br>` within a paragraph can display subtle hints to distinguish line breaks from new paragraphs. Switch to Source view to inspect the original newlines, trailing spaces, and tags.

The Headings feature manages the display and editing boundaries of `#` markers when creating, splitting, or removing heading formatting. The current content theme controls heading fonts and colors.

## Settings

Open **Settings → ParaFlow → Editing**:

| Setting | Purpose |
| --- | --- |
| Paragraph & line-breaking | Enable paragraph spacing and line-break editing |
| HTML break markers | Show hints for tags such as `<br>` |
| Indent first line | Adjust the display of the first line of body paragraphs |
| Paragraph spacing | Adjust the distance between paragraphs |
| Tab display, Tab width | Choose fixed width or tab stops and set their width |
| Headings | Enable heading marker and editing behavior |

First-line indentation, paragraph spacing, and tab display affect layout while preserving source characters. Body tab width uses spaces in the current content font; Source view has a separate tab setting.
