## 尝试功能

在实时预览中打开一份展示笔记，做一处小修改，再与源码视图和阅读视图对比。设置位于 **设置 → ParaFlow**，分为 **主题**、**编辑** 和 **其它** 三个子页面。也可以通过 Obsidian 的设置搜索找到并调整具体选项。

安装、源码构建、平台支持和贡献方式见[项目 README](../README.zh.md)。[英文索引](README.md)提供对应的英文指南。
